# Fix auth test 401s

## Root cause
Demo admin credentials in `src/db.ts` are `admin@ambros.com` / `admin123`, but tests authenticate with `adm@adm.com` / `123`. Login therefore fails and all downstream requests return 401.

## Changes
1. `src/db.ts` `seed()`: change admin user email to `adm@adm.com` and senha_hash to `123`.
2. `src/db.ts` `ensureDemoUsers()`: change admin demo user accordingly.

## Validation
Run test suite (vitest).
